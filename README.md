# Hospital-Management-System
Hospital management system developed using Python and MySql to manage hospital-related information efficiently.

## Technologies Used

- Python
- Streamlit
- MySQL
- MySQL Connector

## Features

- Patient registration
- Patient information management
- Doctor information management
- Appointment managements
- Retrieving patient and hospital information
- MySQL database connectivity
- CRUD operations

## Project Structure

- `streamlit_hospital.py` - Main Python application
- `hospital_management.sql` - SQL database and table creation queries
- `README.md` - Project documentation

## How to Run

1. Install Python.
2. Install the required packages:

```bash
pip install streamlit mysql-connector-python
